ToxicFrame

BETA

A free, open-source Warframe companion for Windows. Your inventory, relics, mastery, rivens and warframe.market trading in one place.

Download for Windows Source code

Linux is planned. The installer is not code-signed yet, so Windows may warn you: click "More info", then "Run anyway".

FeaturesWhat it does

Inventory

Warframes, weapons, mods, arcanes, parts and resources, with prices and where each mod is equipped.

Relics

Your relics with their rewards and plat value, plus a reward overlay during Void Fissures.

Mastery

What you still need for your next rank, and the fastest ways to get there.

Rivens

Search riven auctions, fair-price estimates, and alerts when a good riven is listed.

Trading

warframe.market prices, your orders, and an automatic trade log with profit stats.

Arbitrations

Schedule with community tier grades, alerts for good nodes and live run tracking.

World timers

Open-world cycles, Baro Ki'Teer, Steel Path incursions and weekly resets.

Night City look

A cyberpunk-style interface, or a classic sidebar layout if you prefer.

Is it safe?What it touches

  • The inventory helper opens the Warframe process read-only, finds your session string in memory and uses it only to request your own inventory from Warframe's official API. It never writes to game memory or injects anything, and the session string is never saved, logged or sent anywhere else.
  • Manual inventory updates: choose this on first start (or later in Settings) and the helper only runs when you press Refresh.
  • EE.log: the app reads Warframe's log file from disk to notice trades and mission events.
  • warframe.market: if you sign in, the login token is stored encrypted on your PC. Your password is never saved.
  • Overlays read the screen to show relic reward prices. They never click or send input to the game.

Use at your own risk. ToxicFrame is a fan-made tool and is not affiliated with or endorsed by Digital Extremes. Every line of code is public, so you can check all of the above yourself.
